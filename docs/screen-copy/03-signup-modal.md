# Signup Modal

**Context:** Opens when user clicks "Sign up" on event page

## Modal
- **Title:** Sign up to volunteer
- **Text:** Signing up for [role name]
- **Fields:** Name, Email, Comment (optional)
- **Placeholders:** Your name, you@example.com, Any notes for the organizer?
- **Labels:** Comment (optional)
- **Buttons:** Confirm Signup / Cancel
- **Loading:** Signing up...
