# Signup Cancel

**Route:** `/signup/cancel?token=[token]`

## Already Cancelled State
- **Headline:** Already cancelled
- **Text:** This signup has already been cancelled.
- **Button:** Go home

## Confirm Cancel State
- **Headline:** Cancel signup?
- **Text:** You're cancelling your spot as **[role]** for [event title].
- **Buttons:** Yes, cancel my signup / Keep my signup
- **Loading:** Cancelling…

## After Cancel
- **Text:** Your signup has been cancelled.
- **Button:** Go home
